Error 2502 / 2503

Windows Error 2502 and 2503 can stop an installer from completing.

Possible Causes

  • Windows Installer permissions
  • Temporary-folder permissions
  • Installer service problems

How To Fix

Step 1

Follow the Aeris 2502 / 2503 video guide.

Step 2

Restart Windows and run the installer again.

Step 3

If it still fails, check Windows Installer and temporary-folder access.

Step 4

Send support a screenshot of the exact error if it persists.
