DNS Lookup Failed

Aeris cannot resolve a required network hostname.

Possible Causes

  • DNS configuration
  • Network outage
  • Firewall/router

How To Fix

Step 1

Restart your network connection.

Step 2

Try a different DNS resolver.

Step 3

Check whether other services work normally.

Step 4

If only Aeris fails, provide the exact hostname/error to support.
