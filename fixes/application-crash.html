CRASH

Application Crash Detected

If Fortnite shows a crash report when launching Aeris, reset the local FortniteGame data and retry.

Possible Causes

  • Corrupt local FortniteGame data
  • Damaged build files
  • Installation issue

How To Fix

Step 1

Press Windows + R.

Step 2

Type %localappdata% and press Enter.

Step 3

Find the FortniteGame folder and delete it.

Step 4

Launch Aeris again. If it still crashes, reinstall the build and contact support.
