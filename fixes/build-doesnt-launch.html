Build Doesn't Launch

The build is selected but does not start or immediately closes.

Possible Causes

  • Wrong build path
  • Missing files
  • Runtime dependencies

How To Fix

Step 1

Confirm the build path is correct.

Step 2

Run build verification.

Step 3

Check required Windows runtime dependencies.

Step 4

Review Launcher Setup and retry.
