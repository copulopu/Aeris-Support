Failed to Get Launch Code

Aeris could not retrieve the launch code required to start the build.

Possible Causes

  • Authentication
  • Network/DNS
  • Incorrect system time

How To Fix

Step 1

Verify you are signed in correctly.

Step 2

Check your network and DNS settings.

Step 3

Synchronize Windows date and time.

Step 4

Retry and contact support if it continues.
