Launcher Not Opening

If the Aeris launcher does not open, install the required WebView2 runtime and check your connection.

Possible Causes

  • Missing Microsoft Edge WebView2
  • Network/DNS issue
  • Launcher installation

How To Fix

Step 1

Install the Microsoft Edge WebView2 Runtime, specifically 64-bit.

Step 2

Restart Windows after installing WebView2.

Step 3

Try 1.1.1.1 / WARP.

Step 4

If it still fails, contact support with the launcher error.
