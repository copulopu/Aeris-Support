MSVCP140.dll Missing

Windows reports that MSVCP140.dll cannot be found.

Possible Causes

  • Missing Microsoft runtime
  • Incomplete Windows components

How To Fix

Step 1

Install the current supported Microsoft Visual C++ Redistributable from Microsoft.

Step 2

Restart Windows.

Step 3

Retry Aeris and reinstall the build if necessary.
