Failed to Verify Build Files

Aeris cannot verify the files required by your selected build.

Possible Causes

  • Modified files
  • Missing files
  • Incomplete download

How To Fix

Step 1

Confirm the launcher points to the correct build folder.

Step 2

Make sure extraction/download completed successfully.

Step 3

Run verification again.

Step 4

Contact support with the verification result if it still fails.
